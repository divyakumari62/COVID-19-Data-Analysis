COVID-19 Data Analysis

A data analytics project developed during my Data Analytics Internship to analyze COVID-19 cases, deaths, recoveries, and trends using Python.

Project Overview

The project focuses on cleaning, transforming, analyzing, and visualizing COVID-19 data to identify meaningful patterns and country-wise insights.

Analysis

Country-wise confirmed cases, deaths, and recoveries
Top countries by confirmed cases, deaths, and recoveries
Recovery Rate and Case Fatality Rate (CFR)
Monthly trends of confirmed cases, deaths, and recoveries
Year-wise COVID-19 analysis

Tools

Python | Pandas | NumPy | Matplotlib | Excel | Google Colab

Workflow

Data Collection → Data Cleaning → Data Transformation → Analysis → Visualization
